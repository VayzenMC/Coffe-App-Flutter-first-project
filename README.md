# Coffee App UI - Flutter

> An experimental Flutter implementation of a free Figma UI/UX design kit, built to explore UI translation accuracy and widget structuring.

---

## 📌 Loyiha haqida

Ushbu loyiha Figma'dagi tayyor dizaynni Flutter kodiga o'girish va interfeys elementlarini mukammal moslashtirish bo'yicha tajriba (eksperiment) tariqasida qilingan. Loyiha shaxsiy portfolio va o'rganish maqsadiga mo'ljallangan bo'lib, **tijoriy (kommerskik) maqsadlarda foydalanilmaydi**.

* **Asl dizayn (Figma):** [Freebie Coffee App UI/UX Design](https://www.figma.com/design/qsdZEJhFWzxUkdWdCtxYpC/Freebie-Coffee-App-UI-UX-Design--Community-?node-id=1-8112)

---

## 🚀 Xususiyatlari va Maqsadi

* Figma dizaynidagi ranglar, shriftlar va padding/margin'larni aynan bir xil qilishga harakat qilingan.
* Flutter'da zamonaviy UI komponentlarini qurish bo'yicha amaliy tajriba.
* Kod bazasini toza saqlash va vidjetlarga bo'lib chiqish.
